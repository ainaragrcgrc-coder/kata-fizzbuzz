# Kata FizzBuzz

## Descripción

Implementación del ejercicio FizzBuzz en JavaScript.

La función aplica estas reglas:

- Divisible por 3 → Fizz
- Divisible por 5 → Buzz
- Divisible por 3 y 5 → FizzBuzz
- Si no es divisible ni por 3 ni por 5 → devuelve el número
- Si el dato no es un número → lanza un error
